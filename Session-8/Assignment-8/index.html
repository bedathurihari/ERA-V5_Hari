What the timeline says

2017: attention removes recurrent sequential computation but introduces a quadratic all-pairs bill. 2019–2020: sparse/windowed and linear variants cut sequence compute, while MQA separately attacks decode-time KV bandwidth. 2021–2023: RoPE and ALiBi improve positional inductive biases; context-extension recipes and attention sinks reveal that usable length is not the same as a large context setting. 2024–2026: MLA compresses cached memory; DeltaNet and Gated DeltaNet make recurrent memory more writable; DeepSeek Sparse Attention reduces selected token interactions; DroPE asks whether positional scaffolding should remain after pretraining.

The central lesson: no single technique solves FLOPs, GPU IO, KV storage, effective recall, and extrapolation at once. Position encoding, attention connectivity, recurrent memory, and kernels are different axes, and they can be combined.

Which would I choose?

2K chat: exact softmax with RoPE and FlashAttention: a simple, accurate baseline. 32K–128K assistant: GQA or MLA for decode memory, plus validated RoPE extension if required. Continuous stream: attention sinks or recurrent gated-delta hybrids if bounded memory matters; beware loss of full history. 1M-document agent: sparse retrieval or hybrid attention and explicit external retrieval; a claimed million-token window is not proof of reliable recall.

Additional mechanisms included: Transformer-XL (2019), Performer (2020), FlashAttention (2022), and LazyAttention (2026). FlashAttention is an exact-attention implementation improvement, not a different attention distribution. Sparse attention and compressed KV memory attack different costs.
